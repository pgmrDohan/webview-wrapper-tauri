# Prevent Default

Prevents default browser behaviors in the WebView (context menu, text selection, drag-drop, etc.).

## Activation

Enable in **Setup: Community Plugins** workflow.

## Usage

This plugin works automatically once enabled. No JavaScript API is needed.

It prevents:
- Right-click context menu
- Text selection
- Image drag-and-drop
- Other default browser behaviors

This gives your app a more native feel by removing browser-specific interactions.
